# klava

Офлайн-тренажёр слепой печати для русской (ЙЦУКЕН) и английской (QWERTY) раскладок. Работает без интернета и без установки: достаточно открыть `index.html` в браузере.

## Возможности

- **Уроки** — 23 урока для ЙЦУКЕН и 19 для QWERTY: от основной позиции до верхнего и нижнего рядов, знаков препинания, заглавных букв и цифр. Упражнения генерируются заново при каждом запуске.
- **Слова** — случайные наборы частых слов.
- **Тексты** — отрывки из русской и английской классической прозы: случайные или подряд по книге с запоминанием места.
- **Работа над ошибками** — упражнения из слов с буквами, на которых вы чаще ошибаетесь.
- **Свой текст** — можно вставить любой текст.
- **Статистика** — график скорости, карта ошибок по клавишам, история упражнений, экспорт и импорт в JSON.

Экранная клавиатура подсвечивает следующую клавишу и показывает, каким пальцем её нажимать. Скорость считается в знаках в минуту и в WPM. Есть два режима ввода: курсор стоит на ошибке, пока не нажата правильная клавиша, или ошибки исправляются Backspace. Можно печатать, не переключая раскладку ОС.

## Запуск

```sh
git clone git@github.com:alexander-lun/klava.git
xdg-open klava/index.html
```

Прогресс хранится в `localStorage` браузера.

Тексты взяты из [Викитеки](https://ru.wikisource.org/) и находятся в общественном достоянии. Они приведены к символам, которые есть на клавиатуре (кавычки `"`, дефис `-`), без ударений и сносок.

### Как добавить произведения

Скрипты лежат в `tools/`:

```sh
cd tools
# строка списка: Автор~Название|Заголовок страницы на Викитеке
python3 fetch.py list2.txt out2.json          # для английского: fetch_en.py
python3 build.py ru ../texts-ru.js out1.json out2.json
```

Для русских текстов берите редакции в современной орфографии: на Викитеке они помечены «СО» или «ВТ».
